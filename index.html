The project

2564 Laurier is an infill development. We are replacing one single-family home with six stacked townhomes, each holding three rental units, for 18 homes on a lot that now houses one household.

The building stays in the neighbourhood's scale while using the land far more efficiently. It is designed to be held and operated as a long-term rental.
